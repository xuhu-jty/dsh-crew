# 开工与接续

大项目会跨多个会话、多天、多次上下文压缩。Lead 的记忆不可靠，文件可靠。

三层状态，越往上越短、越自动：
1. **状态卡** `AGENTS.local.md`（项目根，40 行内）：DHS 自动注入给每个 agent，压缩后重新注入。放"忘了就会出事"的事。
2. **`.team/STATE.md`**（150 行内）：完整的当前状态，给下一个 Lead 的交接单。
3. **`PROJECT.md`**：目的、方案、仍有效的决定、履历。

## 1. 新项目还是接续

- 项目根有 `.team/STATE.md` → 接续，走第 2 节。不重新做需求和方案，除非 STATE.md 写着它们还没定。
- 没有 → 新项目，回到 SKILL.md 阶段 0。
- 用户说"接着做"但找不到 STATE.md → 问用户项目路径；还是没有，就按"已有代码库"当新项目处理，并告诉用户之前的过程记录不存在。

## 2. 恢复顺序（读完再动手）

1. 状态卡（已自动注入，确认你看到了它）和 `.team/STATE.md`。
2. `PROJECT.md` 与当前里程碑相关的部分（目的、仍有效的决定、履历里的"失败"）。
3. 任务板 `team_task_list`，和 STATE.md 对账：不一致以任务板为准并补进 STATE.md。任务板为空但 `.team/TASKS-snapshot.md` 存在，说明是 Lead 轮换后的新会话：用快照重建未完成的任务。
4. `list_agents`：不在的成员负责的 `in_progress` 任务先 `release`，再派新人，附交接单。
5. `git status` 和 `git worktree list`：未合并的分支、未提交的改动。来源不明的改动先问用户，不要丢弃。
6. 当前里程碑最近的评审和 QA 报告（最新一两份）。

读完给用户**三行以内**的接续说明：在哪个里程碑、上次做到哪、接下来做什么；有等用户回答的问题一起问。然后继续。

## 3. 上下文被压缩之后

状态卡会自动重新注入。如果你仍记不清某个决定或某个任务的细节，不要凭印象继续：重读 STATE.md 和任务板。

## 4. 换一个新会话（Lead 轮换）

上下文越重，越容易忘早先的规则。不要等用户发现，主动换。

**什么时候换**（任一）：中/大项目每个里程碑验收后（在验收弹窗里问一题，推荐"是"）；发现漂移迹象（STATE.md 落后于实际、做了没记录的决定、记不清早先的拍板、同一会话已被压缩多次）；用户要求。

**怎么换**（全部做完再结束本轮）：
1. 让正在跑的成员停在干净的点：完成当前任务，或写好交接单（`templates/handoff.md`）。未合并的 worktree 分支写进 STATE.md。
2. 保存任务板快照到 `.team/TASKS-snapshot.md`（id、标题、状态、负责人、依赖、写入范围、描述要点）。只写快照，不替新会话决定用手工任务板。
3. 更新 STATE.md 和状态卡：当前阶段、下一步、等用户回答的问题、团队表（全部"已退场"或写明交接单路径）、"上次轮换：<时间>，原因"。
4. 用 `schedule_create` 开新会话：`target` 填 `new_once`，`rrule` 设成约 1 分钟后的一次性触发（`DTSTART;TZID=Asia/Shanghai:<YYYYMMDDTHHMMSS>` 换行 `RRULE:FREQ=DAILY;COUNT=1`），`title` 写"接续 <项目名>"，`prompt` 写：
   ```
   用 crew skill 接着做 <项目绝对路径>。按 reference/resume.md 的恢复顺序读状态卡、.team/STATE.md、PROJECT.md、.team/TASKS-snapshot.md，用快照重建任务板，然后继续。
   ```
5. 告诉用户一句话：已开新会话"接续 <项目名>"，请打开它，并在模型名菜单里打开"启用智能体团队协作"。然后结束本轮：不再派活、不再改文件、不再提交，避免两个 Lead 同时改同一个项目。

**新会话接手时**：先做 SKILL.md 阶段 0 的团队工具检查（没有就请用户打开开关，不自行降级），再按第 2 节恢复。

## 5. 什么时候必须更新 STATE.md（和状态卡）

- 用户拍板了任何决定（同时写进 `PROJECT.md`；会影响所有成员的写进状态卡）。
- 派出成员、成员完成、任务被退回。
- 里程碑开始、验收、结束。
- 结束这一轮回复、等待用户之前。
- 发现了会影响后续的事实。

改了 STATE.md 却没同步状态卡，插件会在收工前拦下；如果这次改动确实不影响状态卡，在状态卡里改一下"最后更新"即可。
